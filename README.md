# 🧭 Guest Search Page – SyriaStay

## 1. Search Filters (Top Section)

A collapsible or sticky filter bar that includes:

* **Destination:** City or Region (dropdown or input)
* **Check-in / Check-out Dates:** Date pickers
* **Guests:** Adults + Children selector
* **Property Type:** Hotel / Private Apartment
* **Price Range:** Slider or min-max input
* **Amenities:** Icons or checkbox (Wi-Fi, Pool, Breakfast, etc.)
* **Discount Badge:** Checkbox: “Show properties with Syrian Passport Discount”
* 🔍 **[Search]** button triggers results refresh

## 2. Search Results (Grid or List View)

Each result card includes:

* 📸 Cover Photo (lazy-loaded, JPEG format)
* 🏨 Hotel/Apartment Name
* 📍 Location (City, region)
* 💰 Price per Night
    * Standard + Discounted (if applicable)
    * Note: "Promo codes available at checkout"
* 🛏️ Guest Capacity
* 🌟 Rating / Stars or Review Snippet
* ✅ Amenity Highlights (icons)
* 🔗 **[View Details]** button → Leads to hotel detail page

## 3. Sorting & Pagination

* **Sort by:** Price (Low–High, High–Low), Guest Rating, Popularity
* **Pagination** or Infinite Scroll

## 4. Optional Enhancements (Future)

* Map View toggle (if available)
* “Save to Wishlist” (Login Required)
* Mobile View Optimizations: Sticky filters & fast card loading
